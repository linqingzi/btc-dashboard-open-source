# 演示截图来源

两张 JPG 均于 2026-10-21 从 Chrome 中实际运行的本机页面直接截取，没有生成、拼接或重绘界面：

- `dashboard-demo.jpg`：默认浏览器视窗中的看板与评分明细，931 × 1178。
- `social-preview.jpg`：同一页面顶部的原始截图裁切，931 × 465，保留醒目的合成数据提示，用于 GitHub 分享预览。

界面和输入对应公开提交 `f4bc83a4b0a5c5b17fb04ba92c9ddeb2be24258a`。所有数值、日期与评分输出来自本仓库的合成示例，截图不含账户或真实行情。

重现画面：在仓库根目录运行 `python3 scripts/generate_demo.py --check`，然后运行 `python3 -m http.server 8080 --bind 127.0.0.1`，在浏览器打开 `http://127.0.0.1:8080`。保持页面顶部的合成数据提示可见，再使用浏览器截图工具捕捉内容区域。字体、浏览器视窗及本地时区可能影响画面的尺寸与日期显示；固定输入及计算结果不变。
